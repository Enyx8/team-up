## О проекте

**Dream-Team** — сайт для поиска команды на хакатон среди студентов.

Что умеет (целевая функциональность):
- Просмотр анкет студентов, которые ищут команду: стек, университет, курс, о себе, статус.
- Публикация запроса команды: «нужно N человек с таким-то стеком/ролью».
- Связь с автором анкеты/запроса (кнопка «Написать» / «Познакомиться»).
- Регистрация и вход (отдельные действия: «Войти» и «Зарегистрироваться»).

Язык интерфейса: **русский**.

## Стек

- Frontend: **React 19 + TypeScript + Vite** (проект развёрнут в папке `frontend/`)
- Backend: **FastAPI + SQLAlchemy + Pydantic** (`backend/`). Анкеты: список, одна, создание, PUT, PATCH, DELETE. Входа нет. Подробный контракт — в `frontend/AGENTS.md`, раздел «Backend».
- БД: **PostgreSQL 16** (зафиксирована, локально запускается в Docker через `docker-compose.yml`, миграции в `database/migrations/`)
- Контейнеризация: **Docker Compose** (поднята локальная БД; см. раздел «База данных и локальное окружение»)

## База данных и локальное окружение (Docker)

Для локальной разработки развёрнут контейнер с PostgreSQL:

- **Конфигурация**: в корне проекта лежат `docker-compose.yml` и `.env.example`.
- **Безопасность**: реальный файл `.env` внесён в `.gitignore` и **никогда не коммитится**.
- **Контейнер**: имя `dream_team_db`, образ `postgres:16-alpine`, том данных `pgdata`, настроен healthcheck (`pg_isready`).
- **База и пользователь**: БД `dream_team_db`, пользователь `postgres`.
- **Порты**: привязка `127.0.0.1:5433:5432`. Порт на хосте вынесен на **`5433`**, так как стандартный `5432` может быть занят локальной службой PostgreSQL / pgAdmin. База открыта только для `127.0.0.1`.

### Команды для запуска

```powershell
Copy-Item .env.example .env     # затем указать свой пароль POSTGRES_PASSWORD
docker compose up -d            # запуск контейнера в фоне
docker compose ps               # проверка: статус должен быть (healthy)
```

### Подключение (для Backend и GUI-клиентов)

- **Строка подключения**:
  `postgresql://postgres:<пароль_из_.env>@localhost:5433/dream_team_db`
- **Параметры для pgAdmin / DBeaver**:
  - Host: `127.0.0.1` (или `localhost`)
  - Port: `5433` (не 5432!)
  - Username: `postgres`
  - Maintenance database: `dream_team_db`
  - Password: пароль из вашего локального `.env`
- **Бэкенд** берёт не эти переменные, а `DATA_BASE_URL` из `.env` (`postgresql+psycopg://...@127.0.0.1:5433/dream_team_db`). Пароль в строке должен совпадать с `POSTGRES_PASSWORD`. В `.env.example` они специально разные — в своём `.env` выровняй.

Сиды: `database/migrations/010_seed_users.sql` и `011_seed_frontend_data.sql`. Хэши паролей там заглушки, войти ими нельзя.

## Дизайн (frontend)

Актуальный интерфейс описан в `frontend/AGENTS.md`. Здесь короткая выжимка, чтобы не откатить старый вид.

- Каталог с API (`GET /listings`). Палитра: коралл `#f78888`, жёлтый `#f3d250`, голубой `#90ccf4`, синий `#5da2d5`, текст `#12344c`. Фон — `frontend/public/page-background.jpg`. Шрифт Sofia Sans.
- «Найти команду» показывает команды (`teams`), «Ищу людей» — студентов (`people`).
- Вход и регистрация — `AuthDialog.tsx` пишет пользователя через `POST /users` и входит через `POST /users/token`. Пароль не хранится на клиенте, в шапке — имя из профиля.
- На карточке команды кнопка «Откликнуться», на карточке студента — «Позвать в команду».
- В форме «Создать анкету» стек выбирается кнопками из `STACK_GROUPS` (`frontend/src/data/catalogOptions.ts`), не свободным текстом. В каталог анкета не попадает, только тост.
- Полная анкета открывается диалогом по клику на карточку. Поле `experience` на экран не выводить. В «Достижениях» заглушка «пока нет, но скоро точно буду»; у команды ниже — бейдж про число мест.
- `Hero.tsx`, `TrustStrip.tsx` и `Footer.tsx` на страницу не выводятся.
- Углы кнопок и карточек небольшие, не капсулы.
