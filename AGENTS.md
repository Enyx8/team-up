## О проекте

**Dream-Team** — сайт для поиска команды на хакатон среди студентов.

Что умеет (целевая функциональность):
- Просмотр анкет студентов, которые ищут команду: стек, университет, курс, о себе, статус.
- Публикация запроса команды: «нужно N человек с таким-то стеком/ролью».
- Связь с автором анкеты/запроса (кнопка «Написать» / «Познакомиться»).
- Регистрация и вход (отдельные действия: «Войти» и «Зарегистрироваться»).

Язык интерфейса: **русский**.

## База данных и локальное окружение (Docker)

Для локальной разработки развёрнут контейнер с PostgreSQL:

- **Конфигурация**: в корне проекта лежат `docker-compose.yml` и `.env.example`.
- **Безопасность**: реальный файл `.env` внесён в `.gitignore` и **никогда не коммитится**.
- **Контейнер**: имя `dream_team_db`, образ `postgres:16-alpine`, том данных `pgdata`, настроен healthcheck (`pg_isready`).
- **База и пользователь**: БД `dream_team_db`, пользователь `postgres`.
- **Порты**: привязка `127.0.0.1:5433:5432`. Порт на хосте вынесен на **`5433`**, так как стандартный `5432` может быть занят локальной службой PostgreSQL / pgAdmin. База открыта только для `127.0.0.1`.

### Команды для запуска

```powershell
Copy-Item .env.example .env     # затем указать свой пароль POSTGRES_PASSWORD
docker compose up -d            # запуск контейнера в фоне
docker compose ps               # проверка: статус должен быть (healthy)
```

### Подключение (для Backend и GUI-клиентов)

- **Строка подключения**:
  `postgresql://postgres:<пароль_из_.env>@localhost:5433/dream_team_db`
- **Параметры для pgAdmin / DBeaver**:
  - Host: `127.0.0.1` (или `localhost`)
  - Port: `5433` (не 5432!)
  - Username: `postgres`
  - Maintenance database: `dream_team_db`
  - Password: пароль из вашего локального `.env`

## Дизайн (frontend)

Дизайн полностью перенесён из визуального прототипа в React-компоненты. **Не переделывать интерфейс с нуля и не откатывать к старой темной палитре** (cream/teal/slate на темном фоне).

### Где интегрирован дизайн

Весь клиентский интерфейс находится в папке `frontend/`:

- **Точка входа и глобальные стили**:
  - `src/main.tsx` → `src/App.tsx` — корневой компонент, объединяющий состояние страницы, модалку, тосты и фильтры.
  - `src/index.css` — основной файл стилей: дизайн-токены в `:root`, типографика, кнопки, сетка, анимации тостов и медиа-запросы адаптива.
  - `index.html` — подключение шрифта **Inter** (веса 400–900), метатеги и заголовок.
  - `src/App.css` — оставлен пустым, параллельные стили не плодятся, единый источник правды — `index.css`.
- **Компоненты интерфейса (`src/components/` и `src/pages/`)**:
  - `src/components/Header.tsx` — шапка сайта: бренд-логотип `dream-team` с фиолетовым бейджем-звездой, навигационные ссылки, кнопка «Войти» и кнопка «Создать анкету».
  - `src/components/Hero.tsx` — главный экран: темная контрастная плашка с заголовком «Большие идеи. Своя команда.», акцентными CTA-кнопками и декоративной карточкой команды «CampusMind AI» с орбитой, аватарами и плавающими статусами.
  - `src/components/TrustStrip.tsx` — полоса ключевых преимуществ (по стеку, из разных вузов, онлайн/очно).
  - `src/pages/DiscoverPage.tsx` — секция каталога: переключатель режимов («Ищу команду» / «Ищу людей»), панель фильтрации, строка счетчика результатов с сортировкой и адаптивная сетка карточек (плюс empty-state, если ничего не найдено).
  - `src/components/Filters.tsx` — панель фильтров: текстовый поиск (по имени, роли, проекту, технологии), селекторы стека, вуза и формата участия, кнопка «Сбросить».
  - `src/components/ListingCard.tsx` — карточка участника или команды: цветной аватар с инициалами, бейдж статуса, название роли/проекта, описание, теги технологий, формат (Онлайн/Очно/Гибрид), кнопка сохранения в закладки и кнопка «Познакомиться».
  - `src/components/CreateListingModal.tsx` — модальное окно на базе нативного `<dialog>` для создания анкеты с переключением типа («Ищу команду» / «Ищу людей»), выбором вуза, формата и стека.
  - `src/components/ToastRegion.tsx` — система всплывающих тост-уведомлений в правом нижнем углу.
  - `src/components/Footer.tsx` — подвал с ссылками и копирайтом.
  - `src/components/Icons.tsx` — библиотека встроенных SVG-иконок.
  - `src/data/demoListings.ts` — демо-набор анкет и списки опций для фильтров (вузы, технологии, форматы).
  - `src/types.ts` — строгая типизация (`Listing`, `FiltersState`, `DiscoverView`, `ToastMessage`).

### Как выглядит дизайн

- **Стилистика**: современный чистый tech-интерфейс на светлой бумажной подложке с выразительными акцентными цветами.
- **Цветовая палитра**:
  - Фон страницы: светлый бумажный (`--paper: #f7f7f4`).
  - Карточки и панели: чистый белый цвет (`--surface: #ffffff`), контуры `--line: #e8e8e3`.
  - Текст и темные элементы: глубокий чернильный (`--ink: #191a25`, `--ink-soft: #343544`, приглушенный `--muted: #777887`).
  - Фирменный акцент: насыщенный фиолетовый (`--purple: #7657f6`, `--purple-dark: #6042e0`, фон `--purple-tint: #f0edff`).
  - Яркий акцент: неоновый лайм (`--lime: #cbfb68`, `--lime-dark: #a9e83a`) для основных кнопок действий и акцентов в заголовках.
  - Пастельные тона аватаров: 5 гармоничных вариантов подложек (`lavender`, `peach`, `blue`, `mint`, `yellow`).
- **Бейджи статусов**:
  - Анкеты студентов (`person`): зеленоватый бейдж (`--green-tint: #e9f8e5`, цвет текста `#3e8150`) — «Открыта к предложениям», «Был на хакатонах», «Готов учиться».
  - Запросы команд (`team`): фиолетовый бейдж (`--purple-tint: #f0edff`, цвет текста `#6b4ee2`) — «Нужен 1 участник», «Финализируем состав».
- **Кнопки**:
  - `.button-primary` — лаймовая с темным текстом;
  - `.button-purple` — фиолетовая с белым текстом;
  - `.button-ghost` — белая с легкой обводкой;
  - `.button-dark` — чернильная для нижнего призыва к действию.
- **Интерактивные состояния**: карточки анкет при наведении плавно приподнимаются (`transform: translateY(-3px)`), подсвечиваются фиолетовой рамкой и мягкой объемной тенью (`--shadow: 0 16px 44px rgba(28, 27, 46, .07)`).
- **Адаптивность**:
  - Десктоп (>980px): 3 колонки карточек, полная панель фильтров в одну строку, расширенная hero-секция.
  - Планшет (701–980px): 2 колонки карточек, перенос полей фильтра.
  - Мобильные устройства (≤700px): 1 колонка карточек, вертикальная компоновка шапки и hero, полноширинный переключатель табов, оптимизированные отступы.
