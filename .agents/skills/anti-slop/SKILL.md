# Anti-slop — Dream-Team

Проектный бриф важнее общего скилла `frontend-design`. Палитра, шрифт и запреты ниже уже выбраны. Не придумывай новую эстетику и не подменяй токены «более смелым» вариантом из общего скилла.

Зона работы: только `frontend/`. Стили — в `frontend/src/index.css`. `frontend/src/App.css` не заполнять. Интерфейс на русском. Иконки — SVG из `frontend/src/components/Icons.tsx`.

Перед новым экраном прочитай [references/README.md](references/README.md).

## Токены

Цвета и радиусы уже лежат в `:root` в `frontend/src/index.css`. Бери их. Новый hex только если Игорь явно попросил новый цвет.

```css
--ink: #191a25;
--ink-soft: #343544;
--muted: #777887;
--paper: #f7f7f4;
--surface: #ffffff;
--line: #e8e8e3;
--purple: #7657f6;
--purple-dark: #6042e0;
--purple-tint: #f0edff;
--lime: #cbfb68;
--lime-dark: #a9e83a;
--coral: #ff8b75;
--blue-tint: #e9f4ff;
--green-tint: #e9f8e5;
--shadow: 0 16px 44px rgba(28, 27, 46, .07);
--radius-lg: 24px;
--radius-md: 17px;
--radius-sm: 12px;
--content: 1180px;
```

| --- | --- | --- |
| `.avatar.lavender` | `#e7dfff` | `#6344c8` |

| `.avatar.mint` | `#d9f4df` | `#2b7550` |

Бейдж студента: фон `--green-tint`, текст `#3e8150`. Бейдж команды: фон `--purple-tint`, текст `#6b4ee2`.

Кнопки не плодить: `.button-primary` (лайм, текст `--ink`), `.button-purple`, `.button-ghost`, `.button-dark`.

Шрифт один: **Inter**, веса 400–900, уже подключён в `frontend/index.html`. Второй шрифт не добавлять. Базовый текст: 15px, line-height 1.5. Заголовок hero уже `clamp(36px, 4.35vw, 58px)`. Длина строки основного текста — до 80 символов.

Шкала отступов. Если в `:root` ещё нет `--space-*`, добавь их один раз и дальше используй только их. Не ставь разовые `9px`, `13px`, `17px`, `23px`.

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 24px;
--space-6: 32px;
--space-7: 48px;
--space-8: 64px;
--space-9: 96px;
```

Контейнер: `width: min(var(--content), calc(100% - var(--space-6)))` на десктопе. На ширине ≤700px боковой зазор — `--space-4`.

## Запреты

- Фиолетово-синие градиенты.
- Один и тот же шаблон «hero + три карточки».
- Эмодзи вместо иконок.
- Одинаковые скруглённые карточки с тенью везде.

Плюс к этому:

- Не возвращай тёмную палитру cream/teal/slate.
- Не подключай API и не меняй демо-типы под бэкенд.
- Не рисуй регистрацию, профиль, страницу анкеты и переписку как готовые экраны, пока Игорь явно не попросил. Если макет всё же нужен, подпиши, что это макет.
- Не добавляй поля, которых нет в демо и в схеме: город на карточке, рейтинг, дедлайн хакатона.
- Тень `--shadow` и подъём карточки `translateY(-3px)` — только у карточки анкеты. Панели, фильтры, тосты и кнопки тенью не копируют.
- Радиус по роли: `--radius-sm` у контролов, `--radius-md` у карточек, `--radius-lg` у крупных панелей. Один радиус на всё не ставить.
- Движение без действия пользователя — одно на экран. `prefers-reduced-motion: reduce` отключает его.

Текущая страница уже содержит hero, полосу из трёх преимуществ и сетку карточек. Этот скилл не велит снести их сам по себе. Новый блок по тому же шаблону не добавляй. Когда Игорь просит редизайн, уходи от шаблона, токены сохраняй.

## Сетка и ритм

- Десктоп (>980px): 3 колонки карточек, фильтры в одну строку.
- Планшет (701–980px): 2 колонки, поля фильтра переносятся.
- Мобильный (≤700px): 1 колонка, шапка и hero столбцом, табы на всю ширину.

Выравнивание каталога и форм — по левому краю. Крупный заголовок может быть короче колонки, но не центрируй весь экран.

## Чек-лист

Перед тем как закончить правку интерфейса:

- [ ] Адаптив на мобильном: ≤700px, затем 701–980px и >980px. Нет горизонтального скролла, кнопки нажимаются пальцем.
- [ ] Контраст текста: обычный текст на своём фоне не ниже 4.5:1, крупный — не ниже 3:1. `--muted` на `--paper` проверь отдельно; если не проходит, темнее сделай существующий токен, новый серый не вводи. Лайм `--lime` не используй как цвет мелкого текста.
- [ ] Состояния hover и focus: hover виден, focus с клавиатуры не убран (`:focus-visible`, обводка уже задана на интерактиве).
- [ ] Пустые состояния: если фильтр или список ничего не нашёл, есть текст, что произошло, и действие (сбросить фильтр или создать анкету). Пустой экран не остаётся белым и без объяснения.
